# Smart Resume Screener

An end-to-end resume screening platform built for the supplied brief. It accepts PDF or text resumes and a job description, extracts candidate data, stores candidates in SQLite, scores each candidate against the job, and presents a ranked shortlist with clear reasons.

## Features

- Upload PDF or text resumes, or paste resume text.
- Extract name, email, phone, skills, education, and estimated years of experience.
- Persist candidates, their source text, and score results in SQLite.
- Score each resume against a job description from 1–10.
- Use OpenAI for semantic assessment when `OPENAI_API_KEY` is configured; otherwise use a deterministic local scorer so the app always works.
- Dashboard for creating job descriptions, screening candidates, viewing results, and deleting test data.

## Architecture

```text
Browser dashboard
      |
      v
FastAPI API + static UI
      |---- PDF/text extraction (pypdf + rules)
      |---- Match service (OpenAI or local fallback)
      v
SQLite: candidates, jobs, assessments
```

## LLM prompt

The app asks the model to return JSON only:

```text
You are an unbiased recruitment assistant. Compare the candidate resume with the job description.
Return a JSON object with score (integer 1-10), matched_skills, missing_skills, strengths,
concerns, and justification. Score evidence in the resume only; do not infer protected traits.
```

The API validates and bounds the returned score. The dashboard also identifies whether a result was generated by OpenAI or the local fallback.

## Run locally

Prerequisites: Python 3.10+ and Git.

```powershell
git clone <YOUR_REPOSITORY_URL>
cd smart-resume-screener
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
uvicorn app.main:app --reload
```

Open http://127.0.0.1:8000. The interactive API docs are at http://127.0.0.1:8000/docs.

To enable semantic LLM scoring, set `OPENAI_API_KEY` in `.env`, then restart the server. Do not commit `.env`.

## API overview

| Method | Endpoint | Purpose |
|---|---|---|
| `POST` | `/api/candidates/upload` | Upload a PDF or `.txt` resume |
| `POST` | `/api/candidates/text` | Save pasted resume text |
| `GET` | `/api/candidates` | List stored candidates |
| `POST` | `/api/jobs` | Create a job description |
| `POST` | `/api/jobs/{job_id}/screen` | Score all candidates for a job |
| `GET` | `/api/jobs/{job_id}/assessments` | Get ranked results |
